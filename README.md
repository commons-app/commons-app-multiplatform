# commons-app-multiplatform
Multiplatform app for uploading photos to Wikimedia Commons from Android and iOS phones.

- Currently a very early-stage prototype that will be worked on at the Wikimedia Hackathon 2026.
- We will be tentatively be using Kotlin Multiplatform and Compose Multiplatform as our tech stack.
